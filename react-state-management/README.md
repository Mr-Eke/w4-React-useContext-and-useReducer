# React State Management

A React app with a light and dark theme switch built with `useContext`, and a task manager built with `useReducer`.

## Requirements

- Node.js 20 or newer
- npm

## Run the App

1. Go into the project folder:
   ```bash
   cd react-state-management
   ```
2. Install the packages:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173/` in your browser.

## Other Commands

| Command | What it does |
|---|---|
| `npm run build` | Checks the types and builds the app into `dist/` |
| `npm run preview` | Serves the built app from `dist/` |
| `npm run lint` | Checks the code for problems |

## How to Use

- Click the button in the top bar to switch between light and dark mode.
- Type a task and press Enter or click **Add Task** to add it.
- Click **X** next to a task to remove it.
